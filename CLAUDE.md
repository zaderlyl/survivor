# Survivor

Survivor-like en navigateur (HTML/CSS/JS sans dépendance), basé sur Swarm de Lino Volle.

## Lancer le projet
```bash
cd src && python3 -m http.server 5173
```
URL : http://localhost:5173

## Structure
```
src/        code source
assets/     images, sons, polices
README.md
```

## Conventions
- kebab-case pour les fichiers, commentaires en français.
- Garder cette même organisation sur tous mes projets.
