# Survivor

Survivor-like en navigateur : tenir le plus longtemps possible face à des vagues d'ennemis, gagner de l'XP et choisir ses pouvoirs.

Base : [07-Swarm](https://github.com/Bebbou/devtober-2026/tree/main/07-Swarm) de Lino Volle, que l'on améliore (armes, synergies, évolutions...).
